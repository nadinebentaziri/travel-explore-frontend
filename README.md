TravelExplore — Travel Agency Website
Responsive travel and tourism website | HTML5 · CSS3 · JavaScript · Bootstrap
Overview
TravelExplore is a frontend website concept for a travel agency, designed to present holiday destinations, travel offers and flight-related information through an accessible multi-page interface. The project highlights web design, page navigation and responsive frontend development.

The original interface uses the name Traveling Agency and includes pages dedicated to travel within Tunisia and international destinations.
Features
- Travel agency homepage: introduction, navigation, agency information and contact section.
- Stay in Tunisia: a dedicated page for local travel offers.
- Trips abroad: cards showcasing international destinations and holiday packages.
- Flights: a separate page dedicated to flight information and travel-related content.
- Login interface: a frontend form for username and password entry.
- Responsive styling: Bootstrap-based layouts and custom CSS.
Project scope: This repository contains a frontend website prototype. The presence of forms and offer pages does not imply a working reservation, payment, user authentication or booking backend. Travel offers displayed in the prototype are illustrative and may be outdated.

Getting Started
1. Clone the repository:
   git clone https://github.com/nadinebentaziri/projecttravel.git
2. Open the project folder.
3. Open index.html in a modern browser. For a better local development experience, serve the folder with a simple local web server (for example, VS Code Live Server).
No application backend or database setup is documented for this frontend prototype.
